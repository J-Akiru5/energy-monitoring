EMU Label Fix

The original backfill script reused devices.name (e.g., ESP32-CICT-001) as the EMU label, violating domain decisions #4 and #9 (EMU identity must survive controller replacement). Fixed to use sequential EMU-NNN scheme with controller-based idempotency gate.
