Installation History with ADR-07 Scoping

RM-06. The installation-history view now exists: a real query and a session-authenticated endpoint, built with ADR-07's scoping from the start rather than retrofitted. A customer sees only their own tenancy periods for an EMU; a Super Admin sees every period. Before this, the only place emu_installations was ever queried was a single-row internal lookup for telemetry stamping — there was no history list at all.

ADR-07 isolation holds against real rows

Read-only check against the fixture EMU: its own customer sees 1 installation (current, with site/building names embedded); a different customer sees 0; the unscoped Super-Admin path sees 1. The explicit customer_id filter is the isolation boundary — the query runs on the service-role client, which bypasses RLS.

Design

ADR-07's decision: "Query installation rows scoped to the caller's own customer_id for non-Super-Admin callers; Super Admin queries are unscoped." That maps to one query function with an optional scope argument and one route that decides which side of the split the caller is on.

  • Query — getInstallationHistory(emuId, customerId?) returns rows newest-first with embedded site/building/customer names. Omitting customerId is the Super-Admin path; the route enforces who may take it.
  • Endpoint — GET /api/installations?deviceId=… in the web app, keyed by device like the rest of the app; the EMU is resolved through the controllers bridge (so history follows the device across controller replacements).
  • Not keyed by EMU id — a caller-supplied EMU id would leak existence across tenants; device-keyed + ownership check avoids that entirely.

Endpoint contract

GET /api/installations?deviceId=<uuid>
Auth: session + view_energy; device must belong to the caller (Super Admin bypass)

200 → { "installations": [
  { "id", "emu_id", "customer_id", "site_id", "building_id",
    "started_at", "ended_at", "created_at",
    "site": { "name" }, "building": { "name" }, "customer": { "name" } }
] }        // newest first; ended_at null = current installation
400 → missing deviceId
401 → not authenticated
403 → not a member / device not in caller's customer
404 → device has no controller bridge (Super Admin path)
500 → unexpected
