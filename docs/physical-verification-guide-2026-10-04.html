On-Site Physical Verification Guide

Part 1 is written for the person at the school site — plain English, no technical terms, about 15 minutes of work. It checks the unit is online and that its main safety switch (the relay) actually cuts power when asked. Part 2 is for Jeff — the pre-test settings that must be corrected first, the firmware reflash status, and the electrician-level voltage test.

Safety first

Please do NOT do these things

Do not open the device box. Do not touch any wires or screws. Do not remove the unit. Everything in Part 1 is done from the website and by watching the appliance — nothing involves opening or rewiring anything. If you see smoke, smell burning, or hear unusual crackling, stop immediately, keep away, and contact Jeff. If the unit is in a locked electrical panel, do not attempt to access it — ask the electrician or facilities staff.

What this device does, in plain terms

The unit measures how much electricity an appliance uses and can switch that appliance's power on or off remotely. It also has a built-in safety feature: if the voltage becomes too high or too low, it is supposed to cut the power by itself to protect the equipment. This visit checks that the remote on/off switch physically works, and later a qualified electrician will check the automatic safety cut.

What you will need

  • A phone or computer with internet access
  • The website address and login that Jeff will give you
  • A small appliance connected to the unit that is okay to switch off for a few seconds (for example a lamp) — confirm with whoever uses it first
  • About 15 minutes, and a way to take 2–3 photos

The three tests

Test 1 — Is the unit online and measuring?

  1. Log in to the website with the account Jeff provided.
  2. Find the device named ESP32-CICT-001.
  3. It should show online (not "offline"), and the voltage/power numbers should change every few seconds.
  4. Write down what you see. If it says offline or the numbers never change, note that and go to "What to send back".

Test 2 — Does the remote power switch physically work?

  1. Open the relay/control page for ESP32-CICT-001 (the page with Trip / Reset buttons).
  2. Press Trip (turn off).
  3. Watch the appliance: within a few seconds it should turn off. You may hear a small click from the device box — that click is the switch moving, which is a good sign.
  4. Press Reset (turn on). The appliance should turn back on within a few seconds.
  5. Repeat steps 2–4 one more time so you've seen it twice.
If it doesn't work

Try twice, then stop

If the appliance does not turn off or on, do not keep pressing the buttons. Note exactly what happened (did the appliance change? did you hear a click?) and send that to Jeff. Do not open the box to investigate.

Test 3 — Photos

  1. One photo of the device box (closed, as it is — do not open it).
  2. One photo of the appliance you tested.
  3. One photo of the website screen after the test (showing the device and the button you used).

The automatic safety cut (over/under-voltage) is tested separately by a qualified electrician with special equipment. You do not need to do anything for that. Do not attempt it yourself.

Pre-test setup (required) — two live config problems

Finding 1

Duplicate alert_thresholds rows make the thresholds non-deterministic

Live has two rows: id=1 (OV 241 / UV 200 / OC 90) and id=2 (OV 200 / UV 200 / OC 95). Reads use .limit(1).single() with no ORDER BY, and the admin PUT updates whichever row it happens to fetch — so the effective threshold can flip, and edits can appear not to stick. Note OV=200 is below a 220 V nominal supply — if that row is the one in effect, "overvoltage" fires on normal voltage. The staging fetch returned 200/200/95, i.e. row 2 was in effect at that moment.

-- inspect
SELECT id, overvoltage, undervoltage, overcurrent, updated_at FROM alert_thresholds ORDER BY id;

-- keep ONE canonical row with correct values, remove the other (example)
UPDATE alert_thresholds SET overvoltage = 250, undervoltage = 200, overcurrent = 80, updated_at = now() WHERE id = 1;
DELETE FROM alert_thresholds WHERE id <> 1;
Finding 2

The device's local safety trip is currently disabled

relay_config.auto_trip_enabled = false for ESP32-CICT-001, and /api/thresholds/esp32 maps that flag straight to the firmware's localSafetyEnabled. So the unit's local over/under-voltage cut is off right now — the physical safety test would be meaningless until it's enabled. Also trip_on_undervoltage = false while trip_on_overvoltage = true.

-- ONLY after the threshold row above is corrected, or the unit may trip at normal voltage
UPDATE relay_config
SET auto_trip_enabled = true, updated_at = now()
WHERE device_id = 'd566ef3b-3e6e-4ed2-acb7-9de59aaf4d6b';   -- ESP32-CICT-001

-- decide the trip flags you want verified, e.g.:
UPDATE relay_config SET trip_on_undervoltage = true WHERE device_id = 'd566ef3b-3e6e-4ed2-acb7-9de59aaf4d6b';

Power-cycle the unit afterwards — the firmware fetches thresholds + localSafetyEnabled at boot, so it won't pick up the change until restarted.

Code follow-up (optional): getAlertThresholds() and the admin PUT's row lookup should get a deterministic ORDER BY (and ideally the table should enforce a single row) so duplicates can't silently change behavior again.

The voltage fault test (electrician, latest firmware)

The core of RM-01: prove the relay cuts power on a real over/under-voltage, without any network involved, and stays cut until an explicit reset. Requires a licensed electrician with a variable AC source (variac) on the voltage-sensing input:

  1. With the unit running the latest firmware and auto_trip_enabled=true (Finding 2), confirm the client's Test 2 already showed the relay physically switches.
  2. Electrician raises the sensed voltage above the configured overvoltage threshold (or lowers it below undervoltage).
  3. Expected: the relay cuts the load by itself within a few seconds, with no dashboard action and (ideally) with the network disconnected — the local cut must not depend on the cloud.
  4. Expected: power does NOT come back on its own when the voltage returns to normal; an explicit reset is required.
  5. Record: the voltage at which it cut, the time to cut, whether it stayed cut, and the alert/log entries in the dashboard.
Safety

Qualified electrician only — mains voltage

This involves live mains. Do not attempt it personally if not qualified; do not ask the site contact to do it. If no electrician is available yet, the client's Tests 1–2 and a reflash still close most of the loop — the auto-cut remains the one open item.
