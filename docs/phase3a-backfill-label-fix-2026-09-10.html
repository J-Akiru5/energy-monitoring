Phase 3a — EMU Label Fix

Phase 3a 2026-09-10 Backfill script update

Problem

The original backfill script reused devices.name (e.g., ESP32-CICT-001) as the EMU label. This tied EMU identity to device/controller identity, violating domain decisions #4 and #9:

  • Decision #4: EMU identity must survive controller replacement
  • Decision #9: EMU identity must be independent of controller identity

Because EMU labels were derived from device names, if a controller was replaced and the device renamed, the EMU would lose its historical identity.

Fix Applied

EMU Label Scheme

EMUs now use a sequential numbering scheme independent of device/controller naming:

EMU-001, EMU-002, EMU-003, ...

The counter reads the current max from existing EMU labels matching the pattern ^EMU-\d+$, so reruns continue the sequence correctly.

Idempotency Check

Previously, the idempotency check looked up EMUs by label = v_device.name. Now it checks controllers.legacy_device_id — if a controller already bridges this device, the device was already backfilled and all entity creation is skipped.

Unchanged

  • Installation and config lookups key on emu_id (not label) — no change needed
  • Telemetry stamping works via v_emu_id and v_controller_id — unchanged
  • Customer/site/building idempotency — unchanged

Logic Comparison

Before (Broken)

-- EMU lookup: tied to device name
SELECT id INTO v_emu_id
FROM emus
WHERE label = v_device.name
  AND owner_customer_id = v_customer_id
LIMIT 1;

IF v_emu_id IS NULL THEN
  INSERT INTO emus (label, ...)
  VALUES (v_device.name, ...);  -- label = 'ESP32-CICT-001'
END IF;

-- Controller lookup: separate from EMU
SELECT id INTO v_controller_id FROM controllers
WHERE legacy_device_id = v_device.id;

After (Fixed)

-- EMU counter: read max from existing labels
SELECT COALESCE(MAX(CAST(SUBSTRING(label FROM 'EMU-(\d+)') AS INTEGER)), 0)
  INTO v_emu_counter FROM emus WHERE label ~ '^EMU-\d+$';

-- Controller lookup FIRST (idempotency gate)
SELECT id INTO v_controller_id FROM controllers
WHERE legacy_device_id = v_device.id;

IF v_controller_id IS NOT NULL THEN
  -- Already backfilled — skip everything
  SELECT emu_id INTO v_emu_id FROM controllers WHERE id = v_controller_id;
ELSE
  -- Create EMU with sequential label
  v_emu_counter := v_emu_counter + 1;
  INSERT INTO emus (label, ...)
  VALUES ('EMU-' || LPAD(v_emu_counter::text, 3, '0'), ...);  -- label = 'EMU-001'
END IF;
