Super Admin Schema

super_admins table — platform-level, outside the tenancy model.
  • user_id — UUID PK, references auth.users(id)
  • granted_by — UUID FK to auth.users(id) (self-granted for bootstrap)
  • granted_at — TIMESTAMPTZ, defaults to NOW()
  • revoked_at — nullable TIMESTAMPTZ; NULL = active, non-NULL = revoked
  • Rows are never deleted — revocation sets revoked_at, preserving the audit trail (decision #24)
  • Partial index on active admins: WHERE revoked_at IS NULL
