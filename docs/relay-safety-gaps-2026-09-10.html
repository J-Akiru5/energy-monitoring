Relay Safety Gaps — Firmware Fix Report

SAFETY FIRMWARE fix/relay-safety-gaps 2026-09-10

1. Problem

Gap 1 — Undervoltage protection wired but disabled

localUndervoltageThreshold is defined (200V default), fetched from the cloud on boot alongside the overvoltage threshold, and the variable exists — but the trip logic in readAndSend3Phase() only checks overvoltage. The comment directly above reads: "Undervoltage/brownout detection disabled to allow single-phase testing." This was left in place through the 3-phase refactor. A brownout condition that sags below 200V on any phase goes undetected by local hardware safety.

Gap 2 — Relay does not reconcile state on boot

main.ino's setup() unconditionally does digitalWrite(RELAY_PIN, HIGH) — power on — on every restart. The WebSocket subscription in relay.cpp only listens to future Postgres changes; it never fetches the current row. A protective trip does not survive a reboot (power blip, watchdog reset, WiFi driver crash) — the opposite of what a safety cutoff is for.

2. Solution

Fix 1 — Undervoltage trip branch

Added three undervoltage branches in monitor.cpp mirroring the existing overvoltage structure: phaseX.voltage < localUndervoltageThreshold && phaseX.voltage > 0. The > 0 guard prevents double-firing during a mains blackout (0V is not brownout — it's a separate condition already flagged as blackout: true). Uses the same localTrip / localTripReason / tripVoltage mechanism.

Fix 2 — Boot-state reconciliation

On boot, after WiFi connects: (a) fetch current relay state from cloud via GET /api/relay?deviceId=... with 5s timeout; (b) fall back to NVS flash if cloud is unreachable; (c) default to power-on only on genuine first boot (no cloud record AND no NVS record). Relay state is persisted to NVS on every trip/reset — including the local hardware trip in monitor.cpp.

NVS implementation using ESP32 Preferences library:

static Preferences nvsPrefs;

void saveRelayStateToNVS(bool tripped) {
  nvsPrefs.begin("relay", false);
  nvsPrefs.putBool("tripped", tripped);
  nvsPrefs.end();
}

bool loadRelayStateFromNVS(bool& tripped) {
  nvsPrefs.begin("relay", true);
  bool hasKey = nvsPrefs.isKey("tripped");
  if (hasKey) {
    tripped = nvsPrefs.getBool("tripped", false);
  }
  nvsPrefs.end();
  return hasKey;
}
