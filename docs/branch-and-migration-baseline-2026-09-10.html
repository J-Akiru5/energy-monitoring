5. How to Make Future Schema Changes

Going forward, use the Supabase CLI for all schema changes:

# Create a new migration
supabase migration new add_device_location_column

# Edit the generated file in supabase/migrations/
# Apply to local dev database
supabase db reset

# Push to production (after review)
supabase db push

Do not hand-write files in packages/database/src/migrations/ anymore. The CLI's migration history in supabase/migrations/ is now the source of truth. The old hand-written files are preserved for reference only.
